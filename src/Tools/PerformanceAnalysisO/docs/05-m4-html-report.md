# M4 HTML 報告

日期：2026-11-13  
範圍：單一檔案、可離線開啟的互動式 HTML 報告。

## 1. 匯出方式

### WPF 應用程式

1. 啟動分析工具並掃描資料。
2. 點擊右上角「匯出 HTML」。
3. 選擇輸出位置。
4. 產生完成後會自動用預設瀏覽器開啟。

報告包含**目前載入的全部場次**；在報告內可切換裝置與場次，不需要重新匯出。

### CLI

```powershell
dotnet run --project src\PerformanceAnalysis.Cli -- scan "D:\TRIOV2\publish_tools\Logs" --html "out\perf-report.html"
```

可與 `--json` 一起使用。

## 2. 報告結構

### 2.1 頂部工具列

- 裝置切換：全部裝置／單一裝置
- 淺色／深色主題切換（預設淺色，方便閱讀與列印）
- 列印 / PDF

### 2.2 總覽

- KPI：檢測場次、裝置數量、任務種類、需要注意
- 歷次 CPU 趨勢（平均／最高）
- 歷次 RAM 趨勢（平均／最高）
- 檢測紀錄表：
  - 場次、裝置、開始、時長
  - CPU 平均／最高、ΔCPU
  - RAM 平均／最高、ΔRAM
  - 任務、警告、基準
- 任務覆蓋矩陣：
  - 列＝場次、欄＝任務
  - 顯示 CPU 平均、未執行、或 —
- 資料品質：
  - 警告／錯誤數
  - 缺少 ref.txt／系統 CSV
  - 摘要訊息

### 2.3 單場次

- 裝置、硬體、OS、時間範圍、樣本數、模式
- 基準徽章與基準差異
- KPI：CPU、RAM、磁碟、網路、辨識、完整率
- 系統 CPU／記憶體圖
- 任務執行時間軸（HTML bars）
- 任務 CPU／記憶體圖
- 任務統計表
- 備註與標籤
- 診斷與資料品質（資訊可展開）

### 2.4 同機多次比較

- 裝置選擇
- 勾選場次（預設基準＋最近場次）
- 基準場次選擇
- 比較表：
  - CPU 平均／ΔCPU／最高
  - RAM 平均／ΔRAM／最高
  - 磁碟、網路、辨識／Δ辨識、完整率、警告
- 時間序列疊圖：
  - 全系統 CPU／已用記憶體／模擬器 CPU
  - 依經過時間對齊
  - 可縮放、拖曳

### 2.5 跨機比較

- 每台裝置選一場
- 硬體規格表：CPU、核心、RAM、OS、GPU
- 硬體不同時顯示「數值僅供參考」
- 比較表與 Δ
- 時間序列疊圖

## 3. 基準與差異

- 總覽：以**同裝置基準**計算 Δ。
- 比較頁：可選擇任一場次作為**全域比較基準**，包含跨裝置。
- 顏色：
  - Δ 變高：紅色
  - Δ 變低：綠色
  - 基準列：顯示「基準」

## 4. 主題與列印

- 預設淺色，適合閱讀與列印。
- 可切換深色；圖表會一起重新繪製。
- 列印按鈕使用瀏覽器列印；CSS 已處理：
  - 隱藏工具列／頁籤／按鈕
  - 卡片避免跨頁
  - 表格不裁切
  - A4 版面
- 可另存 PDF。

## 5. 離線與安全

- 單一 `.html` 檔案。
- ECharts 已內嵌，不從 CDN 載入。
- 不發出外部網路請求。
- 報告資料以 JSON 內嵌，`<` 與 `</script>` 已跳脫。
- 所有文字輸出經 HTML escape。

驗證：瀏覽器 network 只看到本機 HTML 與一個 CSS data URI，沒有外部請求。

## 6. 資料量與降採樣

- 系統序列：CPU、記憶體、影像緩衝、辨識時長。
- 任務序列：任務 CPU、任務記憶體、執行區間。
- 每條序列最多 1,500 點，使用 LTTB 降採樣。
- 目前 10 場報告約 1.2 MB（含 ECharts）。
- 場次非常多時，報告會變大；後續可依裝置拆分或只匯出選取場次。

## 7. 驗證結果

使用 10 個現有場次：

- 報告產生成功，約 1.2 MB。
- 總覽、單場次、同機比較、跨機比較皆可操作。
- 裝置切換正常。
- 深色／淺色切換正常。
- 比較頁 ΔCPU／ΔRAM／Δ辨識正常。
- 沒有 console error。
- 沒有外部網路請求。
- 單元測試增加報告建置與 HTML 輸出檢查，共 32 個測試通過。

## 8. 已知限制

- 報告一次包含全部載入場次，尚未提供「只匯出勾選場次」。
- 場次很多時檔案會較大；尚未自動拆分。
- 跨機比較以絕對值與單一基準差異為主，尚未做核心數正規化。
- 列印時圖表由瀏覽器處理，不同瀏覽器可能有細微差異。
- 尚未提供 PDF 直接輸出按鈕；請使用瀏覽器「列印 → 另存 PDF」。
