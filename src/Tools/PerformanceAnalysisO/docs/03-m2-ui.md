# M2 介面與操作說明

> M3 已補上裝置管理、基準、場次比較、任務覆蓋矩陣與備註，請見 `04-m3-ui.md`。  
> M4 已補上單一 HTML 報告，請見 `05-m4-html-report.md`。

日期：2026-11-12  
範圍：WPF 總覽頁、單場次分析頁、深色主題、ScottPlot 圖表、任務 Gantt。

## 1. 啟動流程

```
啟動
  → 自動載入 D:\TRIOV2\publish_tools\Logs（若存在）
  → 掃描場次
  → 1 場：直接進單場次分析
  → 多場：進總覽
```

其他入口：

- 頂部路徑欄：輸入資料夾後按 Enter 或「掃描」
- 「瀏覽」：原生資料夾選擇器
- 拖曳資料夾到視窗
- `--path <路徑>`：啟動時指定場次或上層目錄
- `--screenshot <資料夾>`：開發／驗收用，輸出 PNG

## 2. 總覽頁

區塊：

1. KPI
   - 檢測場次
   - 裝置數量（依裝置指紋分組）
   - 任務種類
   - 需要注意（警告／錯誤數）
2. 歷次測試 CPU 趨勢
   - X 軸：場次開始時間
   - 兩條線：CPU 平均、CPU 最高
3. 檢測紀錄表
   - 資料夾、裝置、開始時間、時長、樣本
   - CPU 平均／最高、RAM 平均／最高
   - 任務數、警告數
   - 「開啟」按鈕；雙擊列也可進入

操作：

- 表頭可排序
- 點「總覽」回首頁
- 點「返回」回上一個頁面

## 3. 單場次分析頁

由上到下：

### 3.1 標頭

- 場次資料夾
- 裝置名稱／別名
- 警告徽章（警告數、錯誤數、資訊數）
- 硬體：CPU、核心、RAM、OS、Build
- 時間範圍、時長、樣本數、運作模式
- 「開啟資料夾」：用檔案總管開啟原始場次
- 「返回」：回上一個頁面

### 3.2 KPI

| 卡片 | 內容 |
|---|---|
| CPU 平均 | 平均、最高、p95 |
| RAM 平均 | 平均、最高、使用率峰值 |
| 磁碟峰值 | 任務最高 KB/s（自動轉 MB/s）、總量 |
| 網路峰值 | 任務最高 Kbps（自動轉 Mbps）、總量 |
| 辨識時長 | 平均、最高、p95 |
| 資料完整率 | 不重複樣本 ÷ 預期樣本 |

### 3.3 系統圖表

- 系統 CPU：全系統、模擬器、閒置
- 系統記憶體：已用、可用
- 時間軸依場次長度自動選 `HH:mm:ss` 或 `MM-dd HH:mm`
- 深色背景、CJK 字型（Microsoft JhengHei UI）

### 3.4 任務執行時間軸（Gantt）

- 每個任務一列
- 每個執行區間一條 bar
- 空白＝未執行
- 未執行任務顯示「未執行」
- 顏色與任務圖表、統計表一致
- 時間軸依場次長度自動選格式

### 3.5 任務圖表

- 任務 CPU（%）
- 任務記憶體（MB）
- 只使用「執行中」樣本；同一秒重複取平均
- 圖例為任務名稱

### 3.6 任務統計表

欄位：

- 任務
- 狀態（已執行／未執行）
- 執行時間、執行率
- CPU 平均／最高
- 記憶體平均／最高 MB
- 磁碟峰值、網路峰值
- 執行區間數／重啟次數

### 3.7 診斷與資料品質

- 預設只顯示警告與錯誤，依嚴重度排序
- 標頭顯示「N 警告 ・ M 錯誤 ・ K 資訊」
- 「資訊」以可展開區塊呈現（例如 CSV 註解列）
- 沒有警告／錯誤時顯示「沒有警告或錯誤」

### 3.8 原始資料

- 預設收合
- 展開後顯示所有系統樣本（時間、CPU、RAM、影像緩衝、辨識狀態、模式）
- DataGrid 虛擬化，可容納數百至數千筆

## 4. 圖表操作

- 滑鼠滾輪：捲動頁面（避免圖表攔截滾動）
- `Ctrl` + 滑鼠滾輪：縮放圖表
- 圖表內建拖曳平移、右鍵選單（ScottPlot）
- 圖表使用 SkiaSharp 渲染，VM / RDP 環境不需 OpenGL

## 5. 深色主題

- 背景：`#0A1628`
- 面板：`#0D1B30`
- 卡片：`#14243D`
- 主色：`#42A5F5`
- 副色：`#26C6DA`
- 警告：`#FFCA28`
- 錯誤：`#EF5350`
- 字型：Microsoft JhengHei UI
- Windows 10/11 標題列會嘗試啟用深色模式（DWM attribute 20/19）

```

|---|---|
| `overview.png` | 總覽頁 |
| `session.png` | 單場次頂部 |
| `session-middle.png` | 任務時間軸、任務圖表 |
| `session-bottom.png` | 任務統計、診斷、原始資料 |

dotnet run --project src\PerformanceAnalysis.App -- --path "D:\TRIOV2\publish_tools\Logs\20261112_150751" --screenshot "out\shots-single"
```
